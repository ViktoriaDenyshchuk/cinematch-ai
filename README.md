
# 🎬 CineMatch AI

### Інтелектуальний AI-агент для пошуку та порівняння фільмів

CineMatch AI — вебзастосунок, який допомагає користувачам
знаходити та порівнювати фільми за допомогою штучного інтелекту.

Користувач формулює запит природною мовою, а AI-агент
самостійно обирає потрібний інструмент, отримує дані
з MovieLens і формує відповідь українською мовою.

## 1. Проблема та користувачі

Вибір фільму часто потребує перегляду кількох сайтів
для порівняння жанрів, рейтингів і популярності.

CineMatch AI об'єднує пошук та порівняння в одному
чат-інтерфейсі.

Цільова аудиторія — користувачі, які хочуть швидко
знайти фільм відповідно до своїх уподобань.

## 2. Основні можливості

- Пошук фільмів за жанром.
- Фільтрація за роком і мінімальним рейтингом.
- Порівняння двох фільмів.
- Відображення середнього рейтингу та кількості оцінок.
- Посилання на IMDb і TMDB.
- Обробка ситуацій, коли фільм відсутній у базі.
- Журнал дій AI-агента.

## 3. Критерії успіху

1. LLM самостійно обирає інструмент відповідно до запиту.
2. Відповіді ґрунтуються на реальних даних MovieLens.
3. Система коректно повідомляє про відсутні дані
   та не вигадує рейтинги.

## 4. Технології

| Компонент | Технологія |

| Вебінтерфейс | Streamlit |

## 5. Архітектура AI-агента

```text
Користувач
    |
    v
Streamlit (app.py)
    |
    v
AI-агент (agent.py)
    |
    v
Groq LLM
    |
    | Вибір інструмента
    v
+----------------------+
| search_movies        |
| compare_movies       |
+----------------------+
    |
    v
MovieLens (CSV)
    |
    v
Результат інструмента
    |
    v
Groq LLM
    |
    v
Відповідь користувачу
```

AI-агент реалізує цикл Tool Calling.

1. Отримує запит користувача.
2. Передає його мовній моделі.
3. LLM обирає Python-інструмент та його аргументи.
4. Python виконує інструмент.
5. Результат передається назад LLM.
6. Модель формує відповідь користувачу.

Установлено MAX_STEPS = 4.

Умови завершення:
- модель сформувала фінальну відповідь без виклику інструмента;
- досягнуто максимальної кількості ітерацій.

## 6. Інструменти агента

### search_movies()

Пошук фільмів за параметрами:
- genre — жанр;
- min_rating — мінімальний рейтинг;
- year_from — початковий рік;
- limit — максимальна кількість результатів.

### compare_movies()

Порівняння двох фільмів за:
- середнім рейтингом MovieLens;
- кількістю оцінок;
- жанрами;
- посиланнями IMDb і TMDB.

## 7. Джерело даних

MovieLens Latest Small — відкритий навчальний датасет
від GroupLens Research.

У використаній версії:
- 9 742 фільми;
- 100 836 оцінок.

Джерело:
https://grouplens.org/datasets/movielens/

Для роботи використовуються:
- movies.csv
- ratings.csv
- links.csv

Дані зберігаються локально.
Система не використовує рейтинги в реальному часі.

## 8. Встановлення та запуск

### Клонування репозиторію

```bash
git clone git clone https://github.com/ViktoriaDenyshchuk/cinematch-ai.git
cd cinematch-ai
```

### Створення віртуального середовища

```bash
python3 -m venv .venv
source .venv/bin/activate
```

### Встановлення бібліотек

```bash
pip install -r requirements.txt
```


### Підготовка даних

Для роботи застосунку використовується датасет
MovieLens Latest Small від GroupLens Research.

1. Завантажити архів:
   https://files.grouplens.org/datasets/movielens/ml-latest-small.zip

2. Розпакувати архів.

3. Створити папку `data` в корені проєкту.

4. Скопіювати до неї три файли:
   - movies.csv
   - ratings.csv
   - links.csv

CSV-файли не включені до GitHub-репозиторію.
Користувач завантажує їх самостійно з офіційного джерела.


### Налаштування API

Створити файл .env у корені проєкту:

```env
GROQ_API_KEY=your_groq_api_key
```

### Запуск

```bash
python -m streamlit run app.py
```

Відкрити:
http://localhost:8501

## 9. Приклади запитів

- Порадь 5 комедій із рейтингом від 4.
- Знайди фантастичні фільми після 2000 року.
- Порівняй Toy Story та Jumanji.
- Порівняй Toy Story та Completely Fictional Movie XYZ 2099.

## 10. Тестування

### TC-01 — Успішне порівняння

Запит:
Порівняй Toy Story та Jumanji.

Очікувано:
агент викликає compare_movies, отримує рейтинги
та формує правильне порівняння.

Фактично:
Toy Story — 3,92; Jumanji — 3,43.
Виклик compare_movies підтверджено журналом.

Статус: PASS.

### TC-02 — Відсутній фільм

Запит:
Порівняй Toy Story та Completely Fictional Movie XYZ 2099.

Очікувано:
агент повідомляє про відсутність другого фільму,
не вигадує рейтинг і посилання.

Фактично:
інструмент повернув повідомлення
"Фільм не знайдено у MovieLens".
Агент коректно пояснив обмеження.

Статус: PASS.

Детальні сценарії: TEST_CASES.md

Докази: папка screenshots/.

## 11. Обмеження та контроль людини

- Датасет не містить усіх фільмів.
- Дані не оновлюються автоматично.
- Рейтинг MovieLens не є універсальною оцінкою якості.
- Для роботи потрібні інтернет і Groq API.
- LLM може неправильно зрозуміти назву чи жанр.
- Якщо фільм відсутній або результат неоднозначний,
  користувач має уточнити назву та перевірити джерело.

## 12. Компроміси та подальший розвиток

Для MVP обрано локальний MovieLens замість зовнішнього
API з актуальними даними. Це забезпечує відтворюваність
результатів і спрощує тестування, але обмежує актуальність.

План розвитку:
1. Покращення пошуку за назвами.
2. Додавання персоналізованих рекомендацій.
3. Додавання постерів і описів фільмів.
4. Інтеграція з актуальними кінобазами.
